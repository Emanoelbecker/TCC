ROTEIRO DE DESENVOLVIMENTO EM ORDEM
SISTEMA DE GERENCIAMENTO DE DADOS WEB

OBJETIVO DO PROJETO

Desenvolver um sistema web leve de gerenciamento de clientes, produtos e vendas.
O sistema seguirá o padrão arquitetural MVC e será utilizado exclusivamente pelo
administrador autenticado.

Tecnologias planejadas:
- Node.js
- Express
- MySQL
- Sequelize
- Pug ou EJS
- HTML
- CSS
- JavaScript
- express-session
- Argon2id para armazenamento seguro da senha

Escala prevista:
- Aproximadamente 1.000 clientes cadastrados
- Menos de 100 usuários simultâneos
- Apenas um tipo de usuário: administrador

FASE 13 — ITENS DA VENDA E CÁLCULO DO TOTAL
============================================================

Objetivo:
Adicionar produtos à venda e calcular o valor total.

Cada ItemVenda deve possuir:
- idVenda
- idProduto
- quantidade
- valorUnitario

Tarefas:
1. Selecionar produto.
2. Informar quantidade.
3. Obter o preço utilizado.
4. Criar ItemVenda.
5. Calcular subtotal.
6. Somar os subtotais.
7. Atualizar o valorTotal da venda.
8. Permitir vários produtos em uma mesma venda.

Fórmula:

subtotal = quantidade × valorUnitario

valorTotal = soma de todos os subtotais

Exemplo:

Produto A:
10 × 20,00 = 200,00

Produto B:
5 × 30,00 = 150,00

Valor total:
350,00

Critério de conclusão:
Uma venda pode possuir vários itens e o total é calculado corretamente.

IMPORTANTE:
O preço registrado no ItemVenda deve ser preservado mesmo que o preço atual
do Produto seja alterado posteriormente.

REGRA PARA O USO DE IA DURANTE O DESENVOLVIMENTO
============================================================

A IA deverá receber somente uma etapa por vez.

Para cada solicitação, informar:

1. OBJETIVO
   O que deve ser implementado.

2. ARQUIVOS PERMITIDOS
   Quais arquivos podem ser criados ou modificados.

3. REGRAS
   Quais regras do sistema devem ser obedecidas.

4. NÃO FAZER
   Quais partes do sistema não devem ser alteradas.

5. CRITÉRIO DE CONCLUSÃO
   Como verificar se a etapa funcionou.

Exemplo:

OBJETIVO:
Criar o CRUD de Cliente.

ARQUIVOS PERMITIDOS:
clienteController.js
clienteRoutes.js
Cliente.js
views/clientes/

REGRAS:
- Utilizar Sequelize.
- Seguir MVC.
- Todas as rotas devem exigir autenticação.
- CPF deve ser VARCHAR(11).
- CNPJ deve ser VARCHAR(14).
- Não utilizar DOUBLE para valores monetários.

NÃO FAZER:
- Não modificar o sistema de login.
- Não criar CRUD de Produto.
- Não criar CRUD de Venda.
- Não instalar bibliotecas novas sem justificar.

CRITÉRIO DE CONCLUSÃO:
O administrador consegue cadastrar, listar, visualizar, editar e excluir
clientes.


============================================================
REGRA FUNDAMENTAL DO DESENVOLVIMENTO
============================================================

NÃO pedir para a IA criar o sistema inteiro de uma vez.

O ciclo recomendado é:

ETAPA
  ↓
IA gera código
  ↓
Executar
  ↓
Testar
  ↓
Corrigir
  ↓
Commit no Git
  ↓
Próxima etapa

Sempre que uma etapa funcionar, registrar o estado atual antes de começar
a próxima.

Nunca permitir que a IA invente campos, tabelas, relacionamentos ou regras
que não estejam no dicionário de dados ou nas regras de negócio sem que isso
seja explicitamente decidido no projeto.
